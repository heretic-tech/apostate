# Apostate documentation: rules for writers

This directory is the Mintlify site published at docs.apostate.dev. Every
`.mdx` file listed in `docs.json` is a public page. This file and anything in
`.mintignore` are not published.

## Source of truth

- Check every claim against the code before writing it: `python/apostate/`,
  `npm/src/index.ts`, `npm/scripts/cli.mjs`, `patches/`, `config/`,
  `resources/profiles/`, `scripts/`. Old page text is not a source.
- Run what you document. The browser installs with `python3 -m apostate
  install`; `--fingerprint-explain` prints a composed machine without opening
  a window. A code block on a page is either copied from a file in
  `examples/` that was run, or was run by you before it went in.
- Measured numbers (FingerprintJS scores, test results) carry the date, the
  Apostate version, the persona and the host they were measured on. Never
  round a measurement into a claim ("passes FingerprintJS").
- When the code and `.internal/DIRECTIVES.md` (local only) disagree with a
  page, the page is wrong.

## Product position

- Apostate is an anti-detect browser: a Chromium build that presents a machine
  you choose. Free and open source (GPL-3.0), no account, no paid tier.
- Do not name other anti-detect browsers or compare with them. Do not link to
  Heretic from page content.
- Examples and use cases are legitimate work: testing your own site, QA,
  localisation checks, monitoring public pages, ad verification, keeping
  separate sessions for accounts you run, agents working for their user.
  Nothing that helps fraud, ban evasion, fake accounts, scalping, credential
  stuffing or paid CAPTCHA solving.
- A known gap is stated as a gap, with what the reader can do about it. Never
  present it as a feature, and do not write explanations of why something
  cannot be done.

## Terms

| Use | For | Not |
| --- | --- | --- |
| persona | the platform a launch presents: Windows, macOS or Linux | identity, fingerprint profile |
| machine | the specific device a seed composes | device, identity |
| seed | the value of `--fingerprint` | key, id |
| profile | the JSON document of values (`--apostate-profile`) | config |
| user data directory | Chromium's storage directory (`--user-data-dir`) | profile directory |
| host | the computer the browser runs on | server (unless it is one) |
| host mode | `--fingerprint=host` | passthrough, off mode |
| GPU family | a measured set of WebGL and WebGPU values (`--fingerprint-anchor`) | anchor, cluster |
| the Python package, the Node package | `apostate` on PyPI, `@heretic-tech/apostate` on npm | the wrapper |
| switch | a command-line argument to the browser | flag (fine in prose), option |
| option | a keyword argument of the packages | parameter |

## Writing

Pages are interface copy: the reader came to do something. Load the `unslop`
skill before writing and follow its interface register.

- State the fact, the value and the code. One idea per sentence.
- Second person, active voice, present tense. Sentence case headings.
- No em dashes. No colons joining two clauses. No marketing words
  (powerful, seamless, robust, simply, just, easily). No generic intros or
  closing summaries. No emoji.
- Explain a term the first time a page uses it, in one sentence, then link to
  the concept page.
- Exact names: switches, option names, paths, error text, values.
- One warning lives on one page. Other pages link to it.
- Python and Node side by side in `<CodeGroup>` when both apply, Python first.

## Mintlify

- Configuration lives in `docs.json`. Never create `mint.json`.
- Every page has `title` and `description` frontmatter and is listed in
  `docs.json` navigation.
- Internal links are root-relative without an extension: `/guides/proxies`.
- Every code fence has a language. Shell commands use `bash`.
- MDX parses `<` and `{` in prose as JSX. Put placeholders like `<seed>` and
  any braces in backticks or code blocks.
- Components that help: `<Steps>` for procedures, `<CodeGroup>` for
  Python/Node pairs, `<Tabs>` for per-OS instructions, `<Note>`/`<Warning>` for
  one sentence the reader must not miss, `<Card>` for next steps. Do not
  decorate with them.
- Link to repository files with full GitHub URLs:
  `https://github.com/heretic-tech/apostate/blob/main/<path>`.
- `reference/gpu-models.mdx` and `reference/font-lists.mdx` are generated by
  `scripts/generate-docs-reference.py`. Edit the script, not the pages.

## Checks

Run from this directory before committing:

```bash
mint validate
mint broken-links --check-anchors --check-redirects
mint a11y
python3 ../scripts/generate-docs-reference.py --check
```

`mint dev` previews the site at http://localhost:3000.
